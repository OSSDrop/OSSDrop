# Drop your tool

1. It must be **open source** (public repo + an OSI license).
2. **Fork → edit README.md → open a PR.** One tool per PR.
3. Add it under the **best-fit category**, in this exact format:

```
- **[Name](homepage-or-repo)** — clear one-line description (what it does, for whom). `LICENSE` · [code](repo) · [docs](url-if-any)
```

4. Keep the description **honest and non-hype** — say what it is, not "the best ever."
5. **You can add your own tool.** That's encouraged — this list is for makers.

## Reviewed for
- Correct format
- A working repo link
- A valid OSI license

## Not accepted
- Closed-source or paywalled-core tools
- Dead or abandoned repos
- Duplicate entries
- Pure marketing copy

That's it. Welcome aboard.
